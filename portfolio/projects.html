How I work

How I build AI systems

Evaluate before shipping

Give every agent a test set, and checks that run before its output reaches a person.

Design for failure

Let uncertain cases degrade gracefully and go to a person, instead of guessing.

Rules where possible, models where needed

Keep predictable steps in plain code, and use models for language, inside clear constraints.

Keep secrets and personal data contained

Keep keys out of logs, verify incoming webhooks, and send a model only the personal data a task needs.

Stay model-agnostic

Write prompts and interfaces that don't depend on one provider, so models can be swapped without a rewrite.

Make it observable

Log what matters, including failures, so problems show up in the data before they show up in complaints.

NZ Electricity Generation and Consumption

MBIE's yearly data turned into a monitoring dashboard for generation by plant type, consumption by sector, and network losses. Pick a year to see it compared with the year before.

Live Power BI report Open full screen

What it shows

  • KPI cards for electricity generated, consumed and lost each year. Each card's call-out compares the selected year with the previous year: actuals, variance, variance % and, for generation, efficiency (the share of generated electricity that was consumed).
  • Conditional colour: call-outs turn green when the year is up on the previous year, and red when it is down.
  • Losses are split into distribution and transmission, with the previous year's total and its variance.
  • Trend chart comparing actual and estimated consumption (lines) against generation (bars), from 2014 to 2022, since actual consumption isn't in the data before 2014.
  • Bookmarks and buttons switch between trends by generation plant type (biogas, hydro, geothermal, wind and more) and by consumption sector (residential, commercial, industrial and more).

Power BI · DAX · bookmarks · conditional formatting

How it's built

DAX: call-out value (PY | Var | Var% | Efficiency%) 
PY Actuals | Var | Var% | Efficiency% (CY vs PY) =
VAR PY = [Electricity Generated PY]
VAR var_varie = [Electricity Varience]
VAR var_perc = [Electricity Variance %]
VAR var_effic = [Energy Efficiency]
VAR symbol_pos = "↑"
VAR symbol_neg = "↓"
VAR Result =
    SWITCH(TRUE(), var_varie >= 0, symbol_pos, symbol_neg)
    & " " &
    IF(
        ISBLANK(var_varie),
        FORMAT(var_varie, "+#,0;-#,0;0"),
        FORMAT(PY, "#,0") & " | " &
        FORMAT(var_varie, "+#,0;-#,0;0") & " | " &
        FORMAT(var_perc, "+0.0%;-0.0%;0%") & " | " &
        FORMAT(var_effic, "#,0%")
    )
RETURN
    Result
DAX: call-out colour (green up, red down) 
001. Electricity Generated KPI color (fx) =
VAR var_nominal = [Electricity Varience]
VAR result =
    SWITCH(TRUE(),
        var_nominal >= 0, "#358686",
        "#B24A4A"
    )
RETURN
    result

Plato's Pizzeria Sales Analysis

A year of orders analysed for the owners: a sales forecast for the next quarter, busiest hours, and which table sizes and pizzas earn the most.

  • Tables of 1 to 4 people brought in about 86% of revenue ($702,852).
  • Two-person tables earned the most, though solo tables were most frequent.
  • Recommended dropping XL and XXL Greek pizza and stocking the four best sellers.
