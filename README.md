# Titus Velpula AI Consulting

The website for my AI consulting work: https://measuredai.co.nz

One page in plain HTML, CSS and a little JavaScript, hosted on GitHub Pages. The slideshow pictures in `images/` are illustrations of example workflows, not real client systems. The enquiry form doesn't send or store anything; it opens a draft in the visitor's own email app.

```
├── index.html    the page
├── styles.css    colours, type and layout
├── script.js     slideshow, example tabs and the enquiry form
├── images/       the five slideshow pictures
├── fonts/        Schibsted Grotesk (SIL Open Font License)
└── favicon.svg
```
